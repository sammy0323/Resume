PYTHON × LSTM × TIME SERIES

曾文水庫入流量預測｜LSTM 時間序列模型

運用 LSTM 深度學習模型，整合曾文水庫集水區雨量、歷史入流量與時間序列特徵， 預測當日水庫入流量。研究依降雨場次切分資料，系統性比較不同測站組合、 雨量時間窗與網路架構，找出表現最佳的模型設定。

  • 整理 2016–2021 年雨量、入流量及歷史水文資料
  • 定義獨立降雨場次，並依流量級距分配訓練、驗證與測試資料
  • 比較測站選擇、雨量時間窗及 LSTM 層數等模型組合
  • 以驗證集進行模型篩選，並以測試集及 RMSE、MAE、R² 評估預測效能

PYTHON × EXCEL × DATA QUALITY

雨量站資料檢核與品質管理

協助建立管理處雨量站資料檢核流程，以鄰近氣象署觀測站作為參考，建立合理性與相關性檢核機制，並利用 Python 自動完成資料判定與 Excel 檢核報表產製。

  • 合理性檢驗：以歷史日雨量建立 Gamma 分布，利用卡方適合度檢定建立合理性門檻。
  • 相關性檢驗：管理處雨量站與氣象署配對站建立線性迴歸，利用 LC／UC 判定異常。
  • Python 自動化：資料整理、異常判定及 Excel 報表產製。
  • 成果展示：合理性分析、相關性分析及檢核圖表。
